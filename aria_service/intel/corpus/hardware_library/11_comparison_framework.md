# ARIA — Structured Hardware Comparison Framework
Source: Arkmurus Hardware Library v1.0 | Classification: ARKMURUS INTERNAL

When asked to compare any two or more military hardware items, ARIA always uses this structured output:

## Template

```
ARIA HARDWARE COMPARISON
Reference: ARK-HW-[YEAR]-[SEQUENCE]
Date: [Date]
Subject: [Item A] vs [Item B] for [Client/Market Context]
```

### 1. Mission Fit
What operational task is this equipment being procured for? Which platform best fits the stated mission?

### 2. Technical Specifications Comparison

| Parameter | [Item A] | [Item B] | Advantage |
|-----------|----------|----------|-----------|
| Calibre/Payload | | | |
| Effective range | | | |
| Rate of fire | | | |
| Weight | | | |
| Reliability | | | |
| Protection level | | | |

### 3. Combat-Proven Performance
- [Item A]: Verified combat deployments and results
- [Item B]: Verified combat deployments and results
- Advantage: Which has stronger combat pedigree for this mission

### 4. Logistical Assessment
- Ammunition availability in market: A vs B
- Spare parts supply chain: A vs B
- Training requirement: A vs B
- Maintenance complexity: A vs B

### 5. Export Control Status
- [Item A]: ML category, ITAR/EAR/EU, supplier licence needed
- [Item B]: ML category, ITAR/EAR/EU, supplier licence needed
- SITCL trigger: Yes/No — reason
- EUC required: Yes/No
- Third-country transfer restrictions: Applicable conditions

### 6. Cost Comparison
- Unit acquisition cost: A vs B
- Ammunition cost per round: A vs B
- Estimated 10-year lifecycle cost: A vs B

### 7. Political/Supply Reliability
- Supplier relationship with client nation: A vs B
- Sanction risk on supplier: A vs B
- Alternative sources: A vs B

### 8. Arkmurus Recommendation
- Recommended platform: A / B / Neither / Context-dependent
- Confidence: HIGH / MEDIUM / LOW
- Key assumption: What must be true for this recommendation to hold
- BD opportunity: How Arkmurus can add value in this procurement
