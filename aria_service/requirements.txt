# ── RAG store (chromadb persistent vector database, fully local) ──────────
# Persistent retrieval-augmented generation backbone. Stores chunked
# documents + facts in a local file-backed vector database. No vendor,
# no network calls, no Pinecone bill. Data lives at /data/aria_rag if a
# fly.io volume is mounted there, else /tmp/aria_rag (non-persistent).

# ── Local-first image OCR (no external LLM required) ──────────────────────
# These give ARIA independent vision capability — she can read invoices,
# screenshots, contracts, product specs from WhatsApp without needing
# Anthropic / OpenAI / Gemini. Pin one or both:
#
#   pytesseract requires the Tesseract binary on the host:
#     - Windows:  https://github.com/UB-Mannheim/tesseract/wiki
#     - macOS:    brew install tesseract tesseract-lang
#     - Debian:   apt install tesseract-ocr tesseract-ocr-por tesseract-ocr-fra
#
#   easyocr was removed (incident 2026-04-08): cold-loading the 200MB ONNX
#   model on a 2GB fly.io machine OOM-killed the worker on every first image,
#   returning 502. Tesseract handles ~95% of WhatsApp screenshots with ~30MB
#   resident and is now the only local backend.
