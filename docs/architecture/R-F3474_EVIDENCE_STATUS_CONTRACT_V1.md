# R-F3474 — Evidence status and verdict contract v1

The executable authority is `aria_service/intel/dd_evidence_standard.py`.
Reports must persist all four axes plus `verdict_fn_version`; presentation may
compose a label but must not replace or reinterpret those fields.

## Verdict derivation table

Rules are evaluated from top to bottom.  The first matching row wins.

| Priority | Condition | Derived verdict |
|---:|---|---|
| 1 | configuration = `not_applicable` | `not_applicable` |
| 2 | configuration = `disabled` | `not_run` |
| 3 | configuration in `not_configured`, `access_basis_missing` | `blocked` |
| 4 | attempt = `not_attempted` | `not_run` |
| 5 | source = `unavailable`, or attempt is a failure outcome | `blocked` |
| 6 | source in `stale`, `degraded`, `unknown`, or attempt = `partial` | `degraded` |
| 7 | match = `match` | `completed_match` |
| 8 | match = `no_match` | `completed_no_match` |
| 9 | valid remaining resolved attempt (`ambiguous` or `unresolved`) | `completed_partial` |

The named sanctions regression is:

`configured × stale × succeeded × no_match → degraded`

It must never render as a clean sanctions result.

## Validation matrix

The complete valid Cartesian matrix is generated by
`evidence_assessment_matrix()`.  Every combination not satisfying these rules is
illegal:

| Rule | Required relationship |
|---|---|
| V1 | A non-configured state requires `unknown × not_attempted × not_evaluated`. |
| V2 | `not_attempted` requires `not_evaluated`. |
| V3 | A failed attempt requires `not_evaluated`. |
| V4 | `succeeded` requires one of `match`, `no_match`, `ambiguous`, `unresolved`. |
| V5 | An evaluated match requires attempt `succeeded` or `partial`. |
| V6 | Source `unavailable` requires a failed attempt. |
| V7 | The supplied `verdict_fn_version` must be supported exactly. |

`AMBIGUOUS` means multiple plausible candidates remain. `UNRESOLVED` means the
resolver lacks enough evidence to resolve any candidate. Neither is a no-match.
`ACCESS_BASIS_MISSING` deliberately remains on the configuration axis: the
technical capability may exist while ARIA is not permitted to use it.

## Authority invariant

Synthesis never upgrades uncertainty or source failure into fact, never discards
corroboration that has deterministically resolved uncertainty, and never closes a
flag. Flag closure is performed only by a versioned deterministic rule or a
versioned human adjudication decision; synthesis consumes closure.

The exhaustive contract test iterates every possible four-axis combination and
proves that it is either present in the generated matrix with one deterministic
verdict or rejected as illegal.
