Diagnosis · where ARIA is falling behind

Four real gaps (and what isn't one)

Separating product gaps from local test noise. Detail in DEEP_DIVE_where_aria_falls_behind.md.

01 The current brain fabricates grounding

DeepSeek tagged domain knowledge as sourced evidence and missed a real contradiction — a customer could receive a confidently-wrong report. This is the strongest case for the DeepSeek→Claude direction, independent of the GDPR driver.

02 The real ceiling is evidence coverage, not the LLM

Leonardo scored AMBER from both brains because Italy's registry isn't wired and its OSINT sweep failed entirely (23 sources = cookie walls). No model swap fixes this — investing in coverage does, and it compounds across every DD.

03 The DD report under-uses the LLM

Verdicts are deterministic (a strength: auditable, model-independent) — but the analytical “so what” layer customers pay for is barely present in the structured report, while the authored answers show what it could be.

04 Claude isn't switch-ready yet

Three cheap blockers: the provider isn't thinking-aware (empty answers until token budget raised), cost tracking undercounts prompt caching, and the 83.5K-char system prompt costs ~$0.11/turn of Claude input.

Not a gap: native segfaults in local search on this Windows/Python-3.14 box are a local-only quirk — production is Linux and unaffected. Local search keys were pulled from the live app and validated before any scored run.
The move

Recommendations, by compounding value

  • Fix evidence coverage first. Wire Italy (Registro Imprese) & Germany (Bundesanzeiger) registries; fix extraction on cookie-walled sources. Raises quality for every DD regardless of model.
  • Harden honesty against the model. Any [CONFIRMED]/[LEDGER] tag must resolve to a real evidence id, else auto-demote — makes ARIA robust to a fabricating brain.
  • Two-tier the brain, don't wholesale-swap. Cheap model for extraction/coverage; Claude for the final decision-grade synthesis. The model_router two-track scaffolding already exists.
  • Ship the 3 integration fixes before any Claude flip. Thinking-aware parsing + budget, cache-token cost tracking, a system-prompt diet — then re-cost each tier against the $300/mo cap.
  • Market model-independence as a moat. Evidence-grounded, model-independent verdicts are honest and auditable — a genuine differentiator.
